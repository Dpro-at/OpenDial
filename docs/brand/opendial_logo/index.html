Before using these as masters

Every file here is traced, not drawn. All of them were vectorised from original-artwork.png. They render faithfully and scale cleanly, but the full-colour marks are roughly 200 colour-band paths each — a colour cannot be changed by editing one value, and a shape cannot be moved without breaking the shading.

The full-colour marks do not survive small sizes. Below roughly 48 px the face and headset collapse into a blob. Switch the viewer to Knockout to see what to use instead: it stays readable to about 32 px, and it is the file the favicon should use.

Nothing here is below 16 px legible. At that size every treatment is a smudge. A purpose-drawn 16 px icon is still missing.

Redrawing the mark as clean editable vector, plus a purpose-drawn icon, is parked in IDEAS.md. It is not Milestone 0 work.
